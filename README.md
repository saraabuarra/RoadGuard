
# 🚨 RoadGuard

### Intelligent Vision-Based Emergency Detection and Action System

RoadGuard is an AI-powered emergency detection system designed to detect **road accidents and roadside fires** using a camera and an intelligent computer vision model. The system identifies incidents, captures evidence, determines the incident location using GPS, and sends emergency alerts to the appropriate authorities.

## ✨ Features

- 🚗 Accident Detection
- 🔥 Fire Detection
- 📍 GPS Location Tracking
- 📹 Video Evidence Recording
- 🚨 Emergency Alert System
- 🤖 AI-Based Object Detection
- 📱 Mobile Application for Incident Monitoring
- 🖥️ Real-Time Incident Dashboard

## 🛠️ Technologies Used

- Python
- YOLOv8
- Computer Vision
- Raspberry Pi 4B
- FastAPI
- Flutter & Dart
- GPS
- Firebase
- Roboflow
- Google Colab

## 🔧 Hardware

- Raspberry Pi 4B (8GB)
- Raspberry Pi Camera Module v2
- SIM7600G-H 4G HAT
- Micro SD Card

## 🧠 AI Model

The system uses a YOLO-based computer vision model trained to detect road accidents and fires.

The dataset was prepared and annotated using Roboflow, while model training and evaluation were performed using Google Colab.

## 📱 Mobile Application

The RoadGuard mobile application provides an incident dashboard where users can monitor detected incidents, view their locations, and access video evidence.

## 🔄 System Workflow

Camera → AI Detection → Incident Verification → GPS Location → Video Evidence → Emergency Alert → Mobile Dashboard
